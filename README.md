# **1. SOLUTION IDEATION**

## **Problem – Hospital Appointment Booking App**

Users find it difficult and time-consuming to book a hospital appointment because of complex navigation, unavailable doctor information, and lengthy booking steps.

### **Crazy 8s Ideation**

Eight quick solution ideas were generated:

1. One-tap appointment booking
2. Doctor search by specialization
3. Calendar-based appointment selection
4. Emergency appointment option
5. Automatic appointment reminders
6. Doctor availability indicator
7. Online consultation option
8. Easy cancellation and rescheduling

### **Low-Fidelity Ideas**

* Simple home screen with a **Book Appointment** button.
* Doctor cards showing name, specialization, and availability.
* Calendar for selecting date and time.
* Confirmation screen displaying appointment details.

---

# **2. CREATING USER STORIES**

1. **As a patient, I want to search for doctors by specialization, so that I can find the right doctor quickly.**
2. **As a patient, I want to view available appointment slots, so that I can choose a convenient time.**
3. **As a patient, I want to book an appointment online, so that I can avoid waiting at the hospital.**
4. **As a patient, I want to receive appointment reminders, so that I do not miss my appointment.**
5. **As a patient, I want to cancel or reschedule an appointment, so that I can manage unexpected changes easily.**

---

# **3. CREATING SCENARIOS**

## **Scenario – Booking a Hospital Appointment**

Ananya needs to consult a doctor but does not want to wait at the hospital. She opens the hospital app on her mobile phone and searches for a dermatologist. She feels slightly worried because she needs an appointment soon. She selects a doctor, checks the available dates, and chooses a convenient time slot. After entering her details, she confirms the appointment and receives a notification. She feels relieved because the appointment was booked quickly without visiting the hospital.

### **Emotional States**

| **Stage**          | **Emotional State**    |
| ------------------ | ---------------------- |
| **Before Booking** | Worried and frustrated |
| **During Booking** | Focused and hopeful    |
| **After Booking**  | Relieved and satisfied |
